# PVR Elite — 3D demo

Interactive 3D model of the PVR Elite gated community, Kanuru, Vijayawada.

Open the page and orbit around, pick a floor, click a room for its details, or
press **Walk through** to explore on foot (W A S D or the arrow keys).

It is one self-contained page: nothing is loaded from anywhere else, so it
looks and behaves the same every time.

**Illustrative model.** Buildings and room layouts follow the project
brochure's floor plans. The basement, site layout, clubhouse and landscaping
are indicative only and are not an official plan.

This is frozen release **v1**. Later versions will be published at separate
paths, so this link never changes.
